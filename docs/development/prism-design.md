# 棱镜数据流

光谱计划集成版0.4.19。

当前来信 → 同一人物的近期往来 → 一次互动分析 → 目标触动与人格评价 → 混合情绪、连续心情、对人感受、关系信号。符合原话与来源条件的明确纠正，同时更新理解记录和可选的主观回忆版本。

实际来信与实际送出的回复 → 全量场景快照 → 话题/时长/安静边界 → 可选批量话题索引 → 可选主观回忆写作 → 场景、痕迹与联想图持久化。

本轮人物、提到的人物、话题和近期经历 → 联想候选 → 心情一致性、显著性、淡化强度排序 → 有时间与来源的主观回忆、相关跨会话原话、可选经历细节。重复平淡经历可以派生熟悉话题，始终保留来源。

主观背景进入本轮临时尾部；不改变稳定系统前缀。关系信号经原话证据核验后供光谱代码融合，棱镜不替代共同现实、承诺和行为决定。

`retrieval`负责相关性、来源与派生归纳；`experience`负责有依据的理解更新与自然重访；`reading_model`在原有分析中提供可选理解和纠正字段。`scene`、`store`、`assoc`维护数据与图一致性。人格参数、淡化周期归当前模块实例所有。

`prism.db`保留场景、痕迹、人物和心情。理解与修订随场景保存，旧字段缺失时按旧数据读取；删除、编辑后重建关联。归纳是现有来源的派生视图，不产生脱离来源的永久标签。

停止、冻结和结果提交继续使用共同运行控制器。默认正常互动不新增独立模型调用；批量话题整理独立开关，关闭时不执行。
