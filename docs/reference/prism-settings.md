# 棱镜核心配置参考

与当前管理界面的设置字段一致。

## 开始使用

启用后即可使用默认人格与记忆设置。在光谱核心设置中开启“使用棱镜核心的心情与回忆”，即可参与角色回复。修改人格设置后保存即可生效。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用棱镜核心 | true | 记录角色主观经历、心情和对人的感受。关闭后停止参与，已有记忆保留。棱镜核心本身不负责向用户发送聊天回复。 |
| 棱镜核心使用的模型 | "" | 用于情绪与关系观察、话题判断和场景整理。留空跟随对话模型，也可选择“模型管理”中保存的其他模型。 |

## 人格与情绪倾向

五项人格数值均为 0～1，0.5 为中间水平。它们影响主观情绪与目标的计算倾向；通常先使用默认值。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 开放性 | 0.6 | 范围 0～1，越高越重视探索、新鲜体验和理解。0.5 表示中间水平；这是情绪与目标计算的倾向，不是固定回复模板。 |
| 尽责性 | 0.5 | 范围 0～1，越高越重视秩序、目标和完成事情。通常先保留默认值，再按角色性格微调。 |
| 外向性 | 0.55 | 范围 0～1，影响情绪表达倾向、活跃程度和恢复速度。越高通常越愿意表达，不保证每条消息都主动回应。 |
| 宜人性 | 0.8 | 范围 0～1，越高越重视关系、体谅与合作。它不要求角色总是顺从，也不直接规定回复内容。 |
| 情绪敏感性 | 0.6 | 对应大五人格的神经质维度，范围 0～1。越高，情绪反应通常越强、恢复较慢；没有人格好坏之分。 |
| 特别在意的事情（可选） | "{}" | JSON目标倍率，如 {"belonging":1.2,"autonomy":0.8}。只影响九种目标的敏感度；需开启精细人格计算。 |
| 精细人格计算 | true | 让人格恢复速度与在意事项影响计算，不直接规定台词。 |

## 经历与回忆

基础记录持续保存；文字回忆按消息数量或会话安静时间整理。记忆淡化不会删除历史场景。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 每多少轮往来整理场景 | 12 | 按收发瞬间计数，正常一问一答约为一轮；默认12轮。话题变化或安静时长也可触发整理。 |
| 生成主观回忆文字 | true | 开启后，用模型将场景写成角色的回忆。关闭后仍保存场景基础记录，但不生成这部分叙述；通常保持开启。 |
| 对话结束后的整理等待（分钟） | 10 | 会话安静多久后封存场景，并在开启回忆文字时整理叙述。不会让这段时间的基础记录等待落盘。 |
| 基础记忆淡化周期（小时） | 72 | 记忆强度减半的参考时长。情绪、显著性和有效重访影响实际淡化；不删除原始记录。 |
| 心情回落半衰期（小时） | 4.0 | 没有新的触动时，心情逐渐靠近人格基调。数值越大，心情延续越久；需大于 0。冻结期间不计时。 |
| 按当前话题联想 | true | 结合当前话题、人物与近期经历寻找相关回忆，无需向量模型。 |
| 批量整理场景话题 | false | 封存时整理连续话题及原话索引，每20条增加一次模型调用；即时情绪分析保留。 |

## 参与角色回复的信息

控制棱镜核心向光谱核心提供哪些背景，不删除已有经历。角色自行决定如何使用。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 共享对当前人物的感受 | true | 允许光谱核心参考角色对当前人物的情感底色。关闭后不提供这部分感受。 |
| 共享当前心情 | true | 允许光谱核心参考角色此刻的主观心情。关闭后不向光谱核心提供心情，棱镜核心内部仍可记录与变化。 |
| 共享相关回忆 | true | 允许光谱核心获取与当前话题和人物相关的主观回忆。关闭后停止向光谱核心提供，不删除已有回忆。 |
| 分享相关的跨会话来信 | true | 提供与本轮话题或提到的人物相关的历史原话，附时间和来源；不固定搬入无关近期消息。 |
| 分享回忆中的活动与见闻 | false | 随相关回忆提供当时活动和已注意到的内容，不提供未留意信息。 |
| 分享情绪表达倾向 | false | 提供含蓄或外显的主观倾向，具体表达仍由角色人设与当前场合决定。 |
