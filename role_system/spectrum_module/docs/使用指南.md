# 光谱核心使用指南

光谱核心管理角色的共同现实、人物认知、记忆、承诺和生活行为。在主面板「人设与运行」配置人设、对话模型与操作员，再到「功能设置 → 光谱核心」开启模块。首次安装没有预设角色或私人数据。

## 数据页面

「光谱数据」按往来、生活、人物、认知、任务、待发、世界书、导演和工具分组。列表支持选择、多选及批量删除；当前页全选与全部筛选结果全选分别操作，删除前确认范围。日常设置使用「功能设置」，内容管理使用「光谱数据」。

## 记忆与人物

人物依平台实例和用户 ID 区分，昵称用于展示。跨会话回忆保留参与者、日期和来源；共同现实、人物私聊与主观理解分别处理。主动回忆由角色选择调用工具，见[主动回忆](../../../ACTIVE_MEMORY.md)。

## 生活与表达

承诺和已发生事件随角色共享生活保存。睡眠与后台推进由各自开关控制，异常冻结暂停有效时间，解冻后继续。对话合并只在私聊生效；分段与正则分别在对应页面启停。语音可作为工具使用，见[语音表达](../../../SPEECH.md)。

## 指令

`/光谱核心` 显示状态和管理入口。`/叙述事实` 提供可感知的客观环境，代码审核不接受指定角色想法或主动行为；`/叙述查看`、`/叙述删除` 管理记录。模块管理要求操作员身份，叙述事实面向场景参与者。

## 世界书与导演

世界书可保存多本，分别选择全局书和当前书，见[世界书使用](世界书使用.md)。剧情导演支持创建、编辑、删除剧情片段并配置触发条件；按需启用，不是每轮必经步骤。每个设置的具体含义见[配置参考](配置参考.md)。
