# 光谱核心配置参考

与当前管理界面的设置字段一致。

## 开始使用

先启用光谱核心并选择使用范围即可开始聊天。角色人设在“人设与运行”中配置，对话模型在“模型管理”中配置；其余功能可按需要开启。原有设置会自动保留，通常不需要逐项调整。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用光谱核心 | false | 开启后，光谱核心负责角色的对话、记忆和生活状态。首次使用先开启此项；关闭后不介入聊天，已有数据保留。 |
| 使用范围 | "private" | 选择只用于私聊，或同时用于私聊和群聊。群聊主动插话另有开关。 |

## 对话与表达

调整近期上下文、生活叙述和工具说明。通常保持默认；角色性格仍由人设与经历决定。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 仅使用光谱核心整理的近期对话 | false | 开启后，用光谱核心保存的真实往来组成按时间排列的聊天消息；关闭后使用平台聊天历史并补充缺漏。不会将整个历史反复拼入临时背景。长期记忆、人物认知和共同生活记录均保留，不删除数据库消息。 |
| 近期对话保留轮数 | 12 | 近期上下文至少覆盖这些来信及其回复。启用光谱核心历史模式时，每四轮批量移动窗口，最多额外保留三轮以减少缓存重建。数值越大，请求越长；长期记忆仍单独召回。 |
| 生活叙述风格 | "**我的日记体散文。用\"我\"写**，记「上一刻 → 现在」这段时间里我真实经历的事：\n我将会用白描手法完成这篇日记体散文。" | 填写角色记录自身经历的写法，例如“我用简洁的第一人称记录这一段经历”。只调整生活叙述风格，留空使用默认写法。 |
| 工具清单显示上限 | 12 | 每次向角色介绍多少个可用工具。超过上限的工具不会列入本轮说明；安装较多工具插件时可适当提高。 |
| 分段发送消息 | true | 开启后，长回复按自然停顿分成多条消息，主动联系、工具发送和补发也生效。关闭则完整发送。管理指令不分段。 |
| 每段文字长度 | 55 | 每段尽量不超过这个字符数；先按句末、换行拆分，长句按分号或逗号再拆。网址、代码和完整英文词保持整体，可能超过此值。范围16–500。 |
| 分段发送间隔（秒） | 1.2 | 相邻消息之间等待多久，范围0–10秒。分段保留完整内容，不裁掉长回复。 |
| 合并连续私聊消息 | true | 私聊收到消息后先等对方说完，再把连续来信一起交给模型，减少重复调用。仅私聊生效；群聊和 / 开头的指令立即处理。每条原始消息仍分别保存。 |
| 私聊停顿等待（秒） | 3 | 从最后一条来信开始等待；期间有新消息会重新计时。默认3秒，范围0.5–30秒。已经开始的回复不会被后来的消息取消。 |
| 一批私聊最长等待（秒） | 15 | 从这一批第一条来信起算，到时即开始处理，避免对方连续发消息时一直不回复。默认15秒，范围1–120秒；模型繁忙时仍需排队。 |

## 人物关系与棱镜核心

管理跨会话身份、私聊信息边界和棱镜核心提供的主观感受。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 记住人物与关系 | true | 按平台用户身份统一记录人物、好感和信任，支持跨私聊与群聊识别同一个人。通常保持开启；关闭后关系变化不再累积。 |
| 保护私聊内容 | true | 开启后，群聊中不提供私聊得知的私事。关闭会放宽私聊与群聊之间的记忆共享范围。 |
| 回忆其他人的相关往来 | true | 提到已认识的人或共同话题时，回忆其他会话的相关往来，并保留人物、来源和时间。是否说出来由AI决定；这项回忆不需要向量模型。 |
| 使用棱镜核心的心情与回忆 | true | 需启用棱镜核心。开启后，角色参考其主观心情、对人感受和相关回忆；关闭后光谱核心仍可运行。 |

## 记忆与原文回看

关键词记忆可直接使用；按意思查找需要另行配置嵌入模型。增加记忆和原文数量会增加请求长度。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 根据话题查找记忆 | true | 开启后，根据当前话题查找相关长期记忆。通常保持开启。 |
| 最近记忆条数 | 4 | 每次回复固定带入多少条最近保存的长期记忆。设为 0 时不提供这一部分。 |
| 相关记忆条数 | 8 | 每次回复额外查找多少条与当前话题相关的长期记忆，与最近记忆去重。增加条数会增加请求长度。 |
| 关键词检索范围 | 24 | 从当前话题提取的检索片段数量上限，实际最少为 4。较长的话题可适当提高，通常使用默认值。 |
| 按意思查找记忆 | false | 开启后，尝试找回用词不同但意思相近的记忆，补充关键词检索。需要在 角色系统 配置可用的嵌入模型；没有时仍使用关键词检索。 |
| 语义检索默认候选数 | 6 | 语义检索没有指定数量时使用此值。实际召回还受最近记忆和相关记忆条数限制，通常无需调整。 |
| 回看更早的对话原文 | false | 开启后，在长期记忆之外提供相关旧对话原话，帮助核对曾经说过的事。不会重复提供已经带入的最近对话。 |
| 旧对话片段数量 | 2 | 每次最多提供多少段相关旧对话。仅在回看对话原文开启时生效。 |
| 片段前后补充条数 | 2 | 找到一条相关原话后，向前和向后各补充多少条消息。例如填 2 时，一段最多包含命中消息及前后共 4 条消息。 |
| 单段旧对话字数上限 | 1500 | 限制每段旧对话的长度，默认 1500 字符。命中的核心消息会保留，周边消息可能截短。 |
| 按意思查找旧对话 | false | 回看原文时，用语义检索补充关键词未找到的片段。需要嵌入模型；首次开启会在后台建立旧对话索引，可能增加嵌入请求。 |
| 旧对话语义候选数 | 12 | 每次语义检索取回多少条旧消息候选，再按会话和片段数量筛选。仅在旧对话语义检索开启时生效。 |
| 记忆压缩模型 | "" | 用于整理现状与长期认知。留空跟随对话模型，可选择模型管理中已保存的配置。 |
| 生活段标题与摘要模型 | "" | 用于生活段结束后的标题和摘要。留空跟随对话模型。 |

## 主动联系与生活推进

独立生活推进在普通调度和剧情导演模式下都可运行，不需要填写剧情素材。两种模式分别使用各自的时间和意愿设置；模型决定是否开口。开启后可能增加后台模型请求。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 记录并跟进承诺 | false | 开启后，记录角色明确说出的具体承诺，并在约定时间尝试跟进。可能产生后台模型请求和主动消息。 |
| 允许独立生活推进 | false | 两种调度模式下，角色都可在聊天安静一段时间后继续自己的生活并决定是否联系他人。没有剧情素材也可运行；启用剧情导演时，时间和意愿门槛使用导演设置。 |
| 主动推进意愿门槛 | 0.3 | 普通调度模式使用，范围 0～1。门槛越高，主动推进越少；剧情导演使用自己的意愿门槛。 |
| 主动推进前的安静时间（分钟） | 40 | 普通调度模式下，该会话安静多久后才考虑独立推进。剧情导演使用其单独设置的安静时间。 |
| 主动推进最短间隔（分钟） | 20 | 普通调度模式下，同一会话两次独立推进之间至少间隔多久。数值越大，后台推进越少。 |
| 后台使用的模型名称 | "" | 旧配置兼容选项：未选择独立模型时，沿用当前接口并覆写模型名称。新配置建议直接选择已保存模型；已选择独立模型的用途不再应用此覆写。 |
| 后台任务检查间隔（秒） | 10 | 后台多久检查一次到期承诺、睡眠和生活任务。间隔越小，响应到期任务越及时；通常保留默认值。 |
| 同行者近期联系范围（分钟） | 20 | 角色想与当前会话之外的人外出时，要求最近在此时间内与对方真实联系过。用于减少把同行者认错；调大更宽松。 |
| 允许主动参与群聊 | false | 需要使用范围包含群聊。开启后，角色可观察未直接叫自己的群消息，并在意愿达到门槛时插话；可能增加请求与主动消息。 |
| 群聊插话意愿门槛 | 0.6 | 范围 0～1。门槛越高，主动插话越少；仅在允许主动参与群聊时生效。 |
| 后台生活与主动消息模型 | "" | 用于后台生活、主动联系和后续约定。留空跟随对话模型。 |

## 睡眠与未读消息

角色可以入睡、暂缓回应并在醒来后查看来信。是否入睡由角色决定，这组设置只控制允许与时长。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 允许角色睡觉 | true | 开启后，角色可以选择入睡，睡眠期间暂停常规回应并收集来信，醒来后继续。此项不规定必须在夜间入睡。 |
| 最短睡眠时间（分钟） | 60 | 角色每次睡眠允许的最短时长。应小于或等于最长睡眠时间。 |
| 最长睡眠时间（分钟） | 600 | 角色睡眠的最长时长，到达上限后唤醒。默认 600 分钟，即 10 小时。 |
| 醒来后查看睡眠期间的来信 | true | 开启后，醒来时将未读来信提供给角色，由角色决定是否回复。关闭后醒来清空睡眠收件箱。 |

## 世界书与背景设定

在光谱核心数据面板管理多本世界书，分别选择全局书和当前书；同时最多使用两本。动态条目仅进入本轮背景，保持人设、合约和历史前缀稳定。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用世界书 | false | 为角色提供跨会话通用的背景、人物和世界设定。条目在光谱面板的“世界书”中编辑；常驻条目持续提供，其他条目按条件触发。 |
| 关键词扫描消息数 | 2 | 包含当前输入在内，扫描多少条真实消息。0保留原有的仅扫描当前输入行为；条目可单独覆盖。导入文件里显式关闭扫描的条目会转换为仅递归。 |
| 每次最多使用的条目数 | 0 | 0 表示不限制条数。仍受世界书篇幅预算限制。 |
| 世界书篇幅比例（%） | 25 | 世界书可占用的估算 token 数，占下方参考上下文长度的百分比。默认 25%；数值越大，允许带入的设定越多。0 会使预算接近零，超过 100 使用默认比例。 |
| 预算参考上下文长度（token） | 32000 | 用于计算世界书预算，默认 32000；配合 25% 时预算为 8000 token。此项只用于预算估算，不会修改模型本身的上下文上限。 |
| 世界书篇幅绝对上限（token） | 0 | 0 表示不另设上限。填正数时，世界书预算取比例预算与此值中的较小者。 |
| 允许条目带出其他条目 | false | 开启后，已触发条目的正文也参与触发词检查，可带出相关设定。通常先保持关闭，确有联动需求再开启。 |
| 条目联动最多检查轮数 | 3 | 仅在条目联动开启时生效，实际最多 10 轮。越大可能带入越多间接相关设定。 |
| 按意思匹配无触发词条目 | false | 开启后，为没有触发词的条目补充语义匹配。需要世界书总开关和可用的嵌入模型；已有触发词的条目仍按触发规则判断。 |
| 最少候选条目数 | 0 | 大于0时，自动扩大历史扫描直到找到这些候选，或达到最大扫描消息数。概率和预算仍生效，所以最终注入可能更少。启用此项时不做递归扫描。 |
| 自动扩扫最多消息数 | 20 | 仅在设置了最少候选条目数时生效；默认最多回看20条真实消息。 |

## 角色自述思考 · 实验功能

先开启总开关，再选择对应模型模式。实验功能不保证控制模型原生推理；关闭总开关即可使用普通回复流程。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用角色思考记录 | false | 实验角色控制总开关；关闭后两个模型模式均不介入。开启后还需选择对应模式。 |
| DeepSeek 思考续写模式 | false | DeepSeek 前缀续写实验模式，需 beta 接口并选择 DeepSeek 模型类型；未满足条件使用普通合约。 |
| Gemini 思考续写模式 | false | Gemini 角色自述实验模式，使用已闭合的角色背景，不伪造或修改供应商原生思考签名。 |

## 剧情导演 · 调度

可选功能。启用后使用这组主动推进设置；剧情素材和故事线在光谱面板编辑。只想正常聊天时可以保持关闭。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用剧情导演 | false | 开启后，由导演统一安排后台生活推进、剧情素材和任务优先级；关闭后使用普通调度。普通聊天不需要开启导演。 |
| 重启后的等待时间（秒） | 60 | 重启后，导演等待多久再安排剧情任务，给机器人连接恢复留出时间。默认 60 秒。 |
| 每次最多安排的任务数 | 2 | 一次后台检查最多安排多少个导演回合，避免多项任务同时推进。 |
| 主动推进前的安静时间（分钟） | 40 | 导演模式下，某个会话至少安静多久才考虑继续推进。每个会话单独计算。 |
| 停止主动推进的闲置时长（分钟） | 0 | 会话长时间没有往来时，不再为它主动推进。0 表示不设置此上限。 |
| 主动推进意愿门槛 | 0.3 | 导演模式使用，范围 0～1。门槛越高，主动推进越少。 |
| 同一会话推进间隔（分钟） | 20 | 导演模式下，同一会话两次主动推进至少间隔多久。记录在重启后仍保留。 |
| 主动消息参考的近期往来数 | 6 | 导演安排主动消息时，参考该会话多少条近期往来。0 表示不提供这部分历史。 |
| 由导演安排记忆整理 | true | 开启后，将记忆整理纳入导演任务队列，同一时间优先整理一个会话；关闭后使用普通整理流程。 |
| 剧情素材刷新间隔（秒） | 60 | 在光谱面板修改剧情素材后，导演最多等待多久重新读取。通常保留默认值。 |
| 剧情规划与素材评估模型 | "" | 用于剧情素材的模型评估与规划，普通问答不会固定触发。留空跟随对话模型。 |

## 剧情导演 · 故事线与收尾

仅在导演模式下生效。管理故事线数量、预计跨度与收尾条件，通常保留默认值。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 允许当前故事收尾 | false | 满足故事收尾条件后，允许选用收尾素材。关闭时持续推进而不自动收尾；故事收尾会改变当前剧情阶段。 |
| 故事收尾前的最少回合数 | 12 | 至少推进多少个剧情回合后，才开始判断是否可以收尾。达到此数不代表立即收尾，仍需满足其他条件。 |
| 剧情回合持续时间（分钟） | 45 | 当前剧情回合持续到此时长后，可结束并选择下一回合。它不代表聊天回复间隔。 |
| 同时进行的故事线总数 | 5 | 已有未结束故事线达到上限时，不再新开故事线。0 表示不限制。 |
| 同类故事线数量上限 | 2 | 限制相同内容功能的故事线同时进行的数量。0 表示不限制；分类来自剧情素材设置。 |
| 同等跨度故事线数量上限 | 2 | 分别限制跨整幕、单个生活段、当场处理这三种跨度的故事线数量。0 表示不限制。 |
| 故事线超期放弃倍数 | 2.0 | 例如填 2，一条计划 3 回合完成的故事线超过 6 回合仍未完成时可放弃。0 表示不自动放弃。 |
| 收尾前至少完成的故事线数 | 1 | 故事至少真正完成多少条线索，才允许收尾。放弃的故事线不计入；0 表示不设置此门槛。 |
| 放宽收尾条件的回合数 | 40 | 推进到此回合数后，可放宽“至少完成的故事线数”要求，但仍需满足最少回合数且没有未结束故事线。0 表示不放宽。 |

## 剧情导演 · 节奏与介入

控制剧情张弛与主动介入的密度。介入额度只管理剧情安排，与模型服务的费用和配额无关。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用剧情张弛节奏 | false | 让剧情经历升温、高峰、回落和休息阶段，影响导演选择素材的时机。仅在剧情导演开启时生效。 |
| 进入高峰的强度门槛 | 0.9 | 剧情强度达到此值时进入高峰。通常使用默认值；提高会减少进入高峰的机会。 |
| 高峰保持时间（分钟） | 5 | 进入高峰后维持多久，再开始回落。 |
| 回落后的休息时间（分钟） | 20 | 高峰回落后休息多久，再允许新一轮升温。 |
| 剧情强度每分钟回落量 | 0.005 | 强度随时间自然降低的速度。0 表示不自然回落；通常保留默认值。 |
| 聊天活跃变化的影响权重 | 0.5 | 聊天比平时突然活跃时，对剧情强度的影响。0 表示不使用此信号；数值越大，升温越明显。 |
