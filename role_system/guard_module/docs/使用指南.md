# 投递哨兵使用指南

投递哨兵是光谱计划的送达模块。在「功能设置 → 投递哨兵」启用并选择私聊、群聊或全部范围，在「投递状态」查看结果。它记录真实发送结果，暂存不可送达期间的来信，恢复后按有效期与批量设置补发。

群聊可查询禁言状态；私聊根据真实发送结果和已有待发消息的恢复试探判断。已发送内容只有收到成功回执才记入角色历史。冻结与送达状态分别管理。

| 指令 | 用途 |
| --- | --- |
| `/哨兵`、`/哨兵 status` | 查看当前会话的状态与积压 |
| `/哨兵 diag` | 查看诊断 |
| `/哨兵 probe` | 检查当前会话 |
| `/哨兵 flush` | 尝试补发 |
| `/哨兵 clear` | 将缺席期来信标记为已处理 |
| `/哨兵 on`、`/哨兵 off` | 手动标记当前会话送达状态 |

指令要求操作员身份。`on/off` 控制会话状态，不是模块总开关；`clear` 不清空待补发队列。具体设置见[配置参考](配置参考.md)。
