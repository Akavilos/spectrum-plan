接入 NapCat、Lagrange 或其他兼容 OneBot v11 的 QQ 客户端。先在客户端登录机器人账号，再按这里的步骤连接；当前角色消息接口使用 OneBot v11。
这里填写客户端提供的地址，不是本平台的管理网址。不同机器需要使用彼此可访问的 IP 或域名。
客户端与本平台填写相同令牌；留空保留已保存值。此令牌与网页管理密钥独立。
默认使用当前网页地址，请确认客户端能访问。容器中的 localhost 不是宿主机；跨服务器连接还需放行对应端口。
下载文件含连接令牌，请私有保存。已有 NapCat 配置时只合并其中的 WebSocket 客户端条目，避免覆盖其他连接。机器人管理系统创建的新实例已自动配置 NapCat 连接。

输出正则
按列表顺序整理 AI 对外文字，再分段发送。聊天记录保留实际发送内容；不裁剪用户输入、生活状态、模型思考和工具参数。首次安装预设默认关闭。基础组合以替换固定套话为主，保留后面的实际内容与句末标点。裁剪预设单独提供，默认关闭；复杂句子请先预览。规则不能代替模型理解或解决记忆问题。
预览整理效果
预览当前页面勾选的规则，不会保存或发送。自定义表达式使用 Python regex 引擎，常用酒馆写法可直接导入；复杂 JavaScript 专属语法不保证等价。
导入与导出规则
支持本系统 JSON 和只作用于 AI 正文的酒馆 JSON。仅显示、仅提示词、角色宏和历史深度等不兼容选项会提示错误，整份导入失败时不改原规则。导入后请先预览并检查开关。导出保存已经生效的规则。
